# Repository purpose

This repository holds weekly exercises for learning scientific computing.

# Working conventions

- Put each week's work in a directory named `weekN/`, where `N` is the week number.
- Follow the user's prompt for each exercise.
- Use Rust when the prompt does not specify a programming language.
- Keep the repository clean and tidy. Do not commit generated files, caches, build artifacts, or unrelated changes.
- Prefer the simplest direct implementation that satisfies the exercise.
